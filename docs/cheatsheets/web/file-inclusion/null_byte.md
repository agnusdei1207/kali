# null_byte

## 개요

PHP에서 문자열 결합 시 NULL 바이트(`%00`)를 섞어 넣으면, 뒤에 이어 붙는 문자열이 무시되는 우회가 가능하다. 구버전 PHP(< 5.3.4)에서 쓸 수 있으나, 최신 PHP에서는 막혀 있다.

## 사용법

```bash
include("languages...../etc/passwd%00".".php");
```

## 각 부분의 의미

| 항목 | 의미 |
|------|------|
| `%00` | NULL 바이트 (문자열 종료 처리) |
| `...../etc/passwd` | 경로 순회로 읽을 파일 |
| `.php` | %00 이후 무시되는 부분 |

## 동작 원리

- `include()`의 첫 번째 인자에 `%00`을 넣으면 그 뒤의 문자열(`.php`)이 무시된다.
- 현재 PHP에서는 이 우회가 동작하지 않는다. 현재는 파일 경로를 정확하게 지정한다.

## 대응

- 경로를 정확히 지정: `include("languages...../etc/passwd")`
- 경로 오염(path traversal) 자체는 `../../../../etc/passwd` 형태로 시도한다.
- 최신 PHP의 `open_basedir` 제약이 기본 적용되므로, 권한 상승 후 접근이 필요하다.

## 참고

- 시험에서는 PHP 파일 인클루전 문제를 풀 때 이 우회가 나오는 경우가 거의 없다.
- 대신 "파일 포함 후 명령 실행" 자체가 곧 공격 경로다.
