# ps (프로세스 확인)

## 개요

현재 실행 중인 프로세스와 쉘의 정보를 확인하는 명령. OSCP 실전에서 자주 쓰인다.

## 사용법

```bash
# 현재 쉘의 프로세스 정보
ps -p $$

# 현재 쉘의 TTY, 실행 시간, 명령어까지
ps -p $$ -o pid,ppid,tty,cmd
```

## 주요 옵션

| 옵션 | 설명 |
|------|------|
| `-p <PID>` | 특정 프로세스만 |
| `-a` | 실행 중인 모든 프로세스 |
| `-u <user>` | 특정 사용자 |
| `-x` | 종료되지 않은 프로세스 포함 |
| `-o` | 출력 컬럼 지정 (예: `pid,tty,cmd`) |

```bash
ps aux
ps aux | grep bash
ps -ef
ps -u root
```

## 결과 해석

```
  PID TTY      TIME     CMD
 1234 pts/0    00:01:23 bash
 5678 pts/1    00:00:05 sshd
```

- `CMD`가 현재 쉘(터미널)을 의미한다. 세션의 TTY가 `pts/N`인지로 현재 세션을 구분한다.
- 권한 상승 전후로 프로세스가 다르게 실행되는지 확인할 때 쓴다.

## 실전 활용

- 리버스 셸 세션이 제대로 안정화됐는지(`pty.spawn` 적용) 확인한다.
- 특정 프로세스가 root로 실행 중인지(`/usr/bin/sudo` 등) 확인한다.
- 증적에는 `ps`의 출력 전체를 남긴다(짧은 부분만으로는 부족).

## 참고

- 이 문서는 Linux 전용이다. Windows에서는 `tasklist`/`Get-Process`를 쓴다(04-privilege-escalation/windows 참고).
- 모든 시도는 합법적인 대상(본인 소유·허가받은 시스템)에서만 실행한다.
