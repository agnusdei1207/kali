# 방법론

침투 테스트 절차를 단계별 일정으로 정리한 문서입니다.

## 전체 흐름

1. 사전 준비
   - 계약 범위 확인
   - 네트워크 구조 파악
   - 대상 목록 확보

2. 열거
   - 네트워크 스캔
   - 서비스 버전 확인
   - 웹 서비스 점검

3. 초기 접근
   - 웹 취약점 활용
   - 기본 자격증명 확인
   - 자격증명 재사용

4. 침투 후
   - 셸 안정화
   - 도구 업로드
   - 자격증명 수집
   - 내부망 탐색

5. 권한 상승
   - 리눅스: sudo, SUID, 권한 설정 파일 확인
   - 윈도우: 서비스, 스케줄러, 권한 확인

6. 보고
   - 취약점 영향 요약
   - 재현 절차
   - 권고 사항
