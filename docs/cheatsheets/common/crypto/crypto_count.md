> 무엇: 해시 문자열의 글자 수로 알고리즘을 가리는 정리 문서다(32 = MD5, 40 = SHA-1, 65 = SHA-256).
> 언제: 해시 값만 주어지고 형식을 모를 때 크래킹 도구를 고르기 전 길이부터 세어 MD5/SHA-1/SHA-256인지 판별한다.
> 조건: `echo -n "<해시>" | wc -c`로 세며 -n을 빼면 개행 1자가 섞여 길이가 1 늘어난다.

32 -> MD5
65 -> SHA-256
40 -> SHA-1

```sh
# count characters
echo -n "844ffc2c7150b93c4133a6ff2e1a2dba" | wc -c
```
