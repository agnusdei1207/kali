# md5sum

## 개요

파일의 MD5 해시를 출력하고, 무차별 비교에 쓴다. 증적 비교에서 "변경되지 않았는가"를 빠르게 확인할 때 유용하다.

## 사용법

```bash
md5sum 파일명
md5sum extracted_image.jpg

# 여러 파일 한 번에
md5sum * > hashes.txt
```

## 결과 해석

```text
d41d8cd98f00b204e9800998ecf8427e  extracted_image.jpg
```

첫 줄의 해시가 파일의 무결성을 나타낸다. 두 머신의 결과를 비교할 때 쓰인다.

## 실전 활용

- 운영체제 업데이트 전후, 파일이 변조되지 않았는지 확인한다.
- 대상 서버에 파일을 내려받은 뒤, 같은 해시를 계산해 검증한다.
- 자주 비교하는 파일이 있으면 변수에 담아두면 편리하다.

## 주의

- 파이썬의 `hashlib.md5`로도 동일 기능을 할 수 있다.
