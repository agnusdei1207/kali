# x509

## 개요

서버가 제공하는 TLS 인증서(X.509)를 내려받아 버전·만료일·인증서 정보(CN, SAN)를 확인한다.
서비스 버전 파악의 한 단계로, 취약점 exploit 검색의 입력이 된다.

## 사용법

```bash
# 원격 서버의 인증서 확인
echo | openssl s_client -connect 10.201.81.37:443 -servername support.futurevera.thm 2>/dev/null | openssl x509 -text -noout
```

- `-servername`: SNI(서버 이름)에 맞는 인증서를 받는다.
- `-connect`: 대상 호스트/IP와 포트.
- `openssl x509 -text -noout`: 인증서 전문 출력.
- `openssl x509 -dates`: 만료일만 확인.

## 결과 해석

```
Certificate:
  Version: 3 (0x2)
  Serial Number: 4A2B...
  Issuer: C=US, O=Let's Encrypt, CN=R11
  Validity
    Not Before: Jan  1 20XX
    Not After : Dec 31 20XX
  Subject:
    CN = support.futurevera.thm
    SAN:
      DNS: support.futurevera.thm
      DNS: futurevera.thm
```

- `Not After`가 지나지 않았는지, 만료되었다면 해당 서비스를 업데이트한다.
- 인증서의 `Issuer`/`SAN`에서 어떤 애플리케이션이 쓰는지 추론하면, 해당 앱의 취약점을 Exploit-DB에서 찾는다.
- TLS 버전(`Protocol version`)과 `Cipher`도 확인: 구버전 TLS는 취약점 exploit의 후보가 된다.

## 추가 확인

```bash
# 인증서의 만료일만
openssl x509 -in cert.pem -noout -dates

# 인증서의 만료일이 임박한지 (24일 이내)
openssl x509 -checkend 86400 -noout
```
