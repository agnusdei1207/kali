# ping

## 개요

ICMP echo 요청으로 대상 호스트가 살아 있는지 확인한다. 네트워크 연결성의 가장 기본적인 확인 수단이다.

## 설치

```bash
sudo apt update
sudo apt install iputils-ping -y
```

## 사용법

```bash
ping -c 4 10.10.10.10
ping -c 1 -W 2 10.10.10.10   # 1회 전송, 2초 타임아웃
```

## 출력 해석

| 항목          | 의미                                                       |
| ------------- | ---------------------------------------------------------- |
| `ttl`         | 패킷이 지나온 라우터 수. OS를 가늠하는 단서가 되기도 한다. |
| `time`        | 왕복 시간(ms). 네트워크 지연 정도.                         |
| `packet loss` | 패킷 손실률. 방화벽이 ICMP를 차단하면 100% 손실.           |

## 실전에서 하는 일

- 대상이 살아 있는지 먼저 확인한다. 핑이 안 되면 대상이 꺼져 있거나, ICMP가 차단된 것이다.
- `ping -c 1`로 빠르게 확인한 뒤, 더 깊은 스캔(nmap 등)을 진행한다.
- 핑이 안 되더라도 포트가 열려 있을 수 있다. 핑 실패만으로 대상을 포기하지 않는다.

## 팁

- 핑이 안 될 때는 `nmap -Pn`(호스트 발견 생략)으로 스캔한다.
- 모든 시도는 합법적인 대상(본인 소유·허가받은 시스템)에서만 실행한다.
