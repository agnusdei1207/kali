# 도구명 사용법 가이드

도구의 목적과 주요 기능을 한두 문장으로 설명합니다.

## 설치

어떻게 설치하고 확인하는지

```bash
# Kali Linux
sudo apt update && sudo apt install -y 도구명

# 설치 확인
도구명 --version
```

## 기본 개념

이 도구를 사용하기 전에 알아야 할 핵심 개념

- 개념 1: 설명
- 개념 2: 설명
- 옵션 A와 옵션 B의 차이

## 빠른 시작 (단계별)

### 1단계: 기본 사용법

가장 간단한 사용 방법

```bash
명령어 기본형
```

설명: 이 명령어가 무엇을 하는가

### 2단계: 옵션 추가하기

더 자세한 결과를 원할 때

```bash
명령어 옵션들
```

각 옵션의 역할:
- `-옵션1`: 설명
- `-옵션2`: 설명

### 3단계: 고급 사용법

더 복잡한 시나리오

```bash
명령어 고급옵션들
```

## 실제 사용 시나리오

### 시나리오 1: [상황 설명]

목표: 무엇을 하려고 하는가

```bash
# 1단계: 준비
명령어 1

# 2단계: 실행
명령어 2

# 3단계: 확인
명령어 3
```

결과 해석: 결과가 나오면 어떻게 읽는가

### 시나리오 2: [상황 설명]

목표: 무엇을 하려고 하는가

```bash
# 단계별 명령어들
```
