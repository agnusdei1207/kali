# Snaffler

- Snaffler — 도메인의 컴퓨터·공유·파일을 순회하며 패스워드·키·설정 파일 같은 시크릿을 규칙 기반으로 골라내는 .NET 도구. 규칙(snaffle rule)은 TOML 파일로 정의된다.
- 도메인 열거 초반에 공유 폴더에 흘러 있는 자격증명·설정 파일을 대량으로 수집할 때, 특정 폴더 하나만 조용히 스캔할 때, 수집 규칙을 커스텀 규칙으로 바꿔 특정 시크릿을 노릴 때.
- Windows .NET 실행 파일(Snaffler.exe), 도메인 전체 스캔에는 유효한 도메인 계정, DC 주소(-c)를 안다.

## 기본 사용

```
Snaffler.exe -s -d corp.local -c dc01.corp.local -v data
```

- `-s`: 결과를 stdout으로 스트리밍. -o를 안 쓸 때는 필수로 붙인다.
- `-d`: 대상 도메인. `-c`: 컴퓨터 목록을 받아올 DC.
- `-v data`: 로그 상세 수준(trace/debug/info/data). data는 매칭된 파일 내용까지 보여준다.

## 파일 저장 / 폴더 단위 스캔

```
Snaffler.exe -s -o C:\temp\snaffler.log -d corp.local -c dc01.corp.local
Snaffler.exe -s -i C:\                     # 컴퓨터·공유 탐색 없이 로컬 경로만
Snaffler.exe -s -n host1,host2             # 컴퓨터 탐색 생략, 대상 목록 직접 지정
```

## 주요 옵션

- `-o <파일>`: 로그 파일 저장. -s와 함께 쓰면 콘솔+파일 동시 출력.
- `-m <디렉토리>`: 매칭 파일을 지정 디렉토리로 자동 복사(snaffle). `-l`: 복사 최대 크기(기본 10MB).
- `-b <0~3>`: 덜 중요한 규칙(LAIM)을 건너뛰는 강도. 소음이 클 때 올린다.
- `-i <경로>`: 공유 탐색 없이 단일 경로 스캔. `-a`: 파일 열거 없이 공유 목록만. `-f`: DFS로만 공유 탐색(조용한 방식).
- `-x <스레드>`: 스레드 수(4 미만은 금지). `-j <바이트>`: 매칭 문자열 앞뒤 문맥 표시.
- `-u`: AD 계정 이름을 모아 검색 규칙에 반영.
- `-z generate`: 기본 규칙을 default.toml로 덤프. `-p <폴더>`: 커스텀 규칙 로드.

## 스낵 규칙 개념

- 규칙은 TOML로 구성되고 확장자·파일명·내용 정규식과 심각도(Class)로 이루어진다. Class가 높을수록 확실한 시크릿이다.
- 콘솔 출력은 등급·유형 태그([3] {Secret} 같은 형태)로 붙으므로 등급 높은 매칭부터 확인하면 된다.

## 팁·트러블슈팅

- 결과가 너무 많으면 -b를 올리고 -v를 data에서 info로 낮춘다.
- 도메인 열거가 실패하면 -c로 준 DC의 DNS·LDAP 접근 권한을 확인. 공유 읽기 권한이 없으면 결과가 비어 보인다.
- 도메인 전체 스캔은 SMB 트래픽이 크다. 조용해야 하면 -i(단일 경로)·-f(DFS)로 범위를 좁힌다.
- -m은 발견 파일을 타깃 디스크에서 복사해 온다. 용량과 탐지 가능성을 감안하고 쓴다.
- DC에서 직접 돌리면 열거 단계가 생략되어 더 빠르게 파일 스캔으로 들어간다.
