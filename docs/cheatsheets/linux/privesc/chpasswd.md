# chpasswd (비밀번호 변경)

## 개요

`chpasswd`는 root 권한으로 계정의 비밀번호를 변경하는 명령이다. 권한 상승 후, root 쉘에서 사용하면 시스템 접근 수단을 확보하는 데 쓴다.

## 사용법

```bash
# 방법 1: 표준 입력
echo "root:새비밀번호" | chpasswd

# 방법 2: 파일에서
cat /tmp/passwd.txt   # root:새비밀번호
chpasswd < /tmp/passwd.txt
```

## 각 부분의 의미

| 항목 | 의미 |
|------|------|
| `root` | 비밀번호를 변경할 계정 |
| `새비밀번호` | 새로 설정할 비밀번호 |
| `/tmp/passwd.txt` | 계정:비밀번호 쌍을 담은 파일 |

- 두 계정을 바꿀 때는 각각 별도로 실행한다.
- `chage -l <계정>`으로 변경 이력을 확인할 수 있다.

## 실전 팁

- root 쉘이 생기면 SSH로 접속하는 새 계정을 만들 때도 이 명령을 쓸 수 있다.
- OSCP 시험의 Windows/Linux 양쪽에서 크리덴셜 획득 후, 권한 상승 경로를 찾을 때 이 명령은 부차적으로만 쓴다.

## 참고

- 이 명령은 Linux 전용이다. Windows에서는 net user로 비밀번호를 변경한다.
