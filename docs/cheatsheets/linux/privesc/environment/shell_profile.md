# shell_profile / .bashrc / .profile

## 개요

쉘 설정 파일은 사용자가 매 세션을 시작할 때 자동으로 실행된다. 권한이 낮은 계정으로 접속했을 때, 이 파일이 재사용될 수 있는 경로 정보(서비스 주소, 배포 경로)를 담고 있을 수 있다.

## 확인

```bash
cat ~/.bashrc
cat ~/.profile
cat ~/.bash_profile
cat /etc/profile
```

## 자주 확인할 내용

| 내용 | 확인 포인트 |
|------|-------------|
| alias, 함수 정의 | 자주 쓰는 명령어의 별칭 |
| PATH에 포함된 디렉터리 | `/usr/local/bin`, `/opt` 등 |
| 환경 변수나 스크립트 경로 | 실행 파일 경로 |
| `sudo`/`su` 관련 alias | 권한 상승 관련 별칭 |

## 실전 활용

- PATH에 악성 바이너리가 있는지 확인한다.
- 특정 디렉터리의 실행 파일이 crontab이나 rc.local로 연결되는지 확인한다.
- root 쉘로 바뀐 후에는 `/etc/profile`, `/etc/bash.bashrc`도 확인한다.

## 참고

- Windows에는 `C:\\Users\\<user>\\.bashrc` 같은 파일이 없다. 설정 파일은 레지스트리와 `Run` 키로 확인한다.
- 증적에는 "무엇을 확인했고, 무엇이 취약한지"를 적는다.
