# find

> 무엇: 이름(-name), 수정 시간(-mtime), 소유자(-user) 같은 조건으로 파일 시스템을 탐색하는 find의 사용법과 자주 쓰는 조합을 정리한 문서
> 언제: 초기 정찰에서 flag·설정·로그 파일 위치를 찾거나 최근 7일 내 수정 파일 같은 변화를 확인할 때 정찰 단계에서 가장 먼저 쓴다
> 조건: 읽기 권한이 있는 경로만 검색되므로 권한 에러는 2>/dev/null로 버리고, 결과가 길면 head·grep으로 좁혀 노트에 기록한다

## 개요

파일 시스템 탐색의 기본 명령. OSCP 정찰 단계에서 가장 자주 쓰인다.

## 사용법

```bash
# 특정 이름의 파일을 찾는다
find / -name "*.txt" 2>/dev/null

# 특정 이름의 파일을 찾고 출력
find / -name "49216.py" 2>/dev/null
```

## 자주 쓰는 조합

```bash
# 최근 7일 이내 수정된 파일을 찾는다
find / -mtime -7 2>/dev/null

# 특정 사용자의 홈 디렉터리만
find /home -user root 2>/dev/null

# 결과를 파일로 남긴다
find / -name "*.log" > /tmp/found.log
```

## 실전 팁

- 출력이 너무 길면 `head`/`grep`으로 좁힌다.
- 대상이 컨테이너이면 `/` 전체가 아니라 `/home`, `/var`, `/opt`부터 확인한다.
- `find` 결과는 노트(05-progress-tracker)에 반드시 적는다.
