# vim

- 편집기 vim의 저장·종료(:wq), 파일 열기(:e), 셸 호출(:sh), 내장 터미널(:terminal), vimdiff 비교 같은 자주 쓰는 명령을 정리한 문서
- 타깃에서 설정 파일·익스플로잇 스크립트를 편집할 때 기본 도구로 쓰고, sudo -l에 vim이 허용돼 있으면 GTFOBins 경로의 권한 상승 도구가 된다
- 쓰기 권한이 없는 디렉터리에서는 백업·임시 파일 생성 때문에 저장이 실패할 수 있어 tee 대체나 디렉터리 권한 확보가 필요하다

## 개요

`vim`은 기본 에디터이자, OSCP 실전에서 "편집기 권한"이 막힌 환경에서도 사용하게 된다. 이 문서는 자주 쓰는 명령어와 함께하는 팁만 정리한다.

## 사용법

```bash
vim filename
vim -R filename          # 읽기 전용 강제
vimdiff file1 file2     # 두 파일을 나란히 비교
```

## 자주 쓰는 명령어

- `:q`: 저장 안 하고 종료
- `:wq`: 저장 후 종료
- `:w`: 저장
- `:e`: 다른 파일을 열기
- `:sh`: 현재 세션 안에서 shell
- `:terminal`: 내장 터미널 열기
- `:colorscheme desert`: 테마 변경

```bash
:colorscheme slate
:set number
```

## 권한이 제한된 환경에서의 팁

- 파일에 쓸 쓰 권한이 없으면 저장이 실패한다(`echo`, `cat`, `tee`는 정상 동작).
- `vim`은 백업/임시 파일을 만들 때 디렉터리 쓰기 권한을 요구한다.
- 위 경우 `tee`로 대체하거나, 먼저 디렉터리 쓰기 권한을 확보한다.
- 확인: `:set backupskip=all` 로 백업 생성을 막을 수도 있다.

## 실전 팁

- 세션(리버스 셸)에서는 `:terminal`로 대용 터미널을 띄워두면 편하다.
- 증적 작성 시 사용한 vim 명령이 있다면 함께 남긴다.
