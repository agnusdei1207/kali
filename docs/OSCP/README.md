# OSCP 준비 전략 — 첫 응시에서 여유 있게 합격

> 직장 병행 · 주 11~15시간 기준. **독립 풀이 → 약점 제거 → 처음 보는 문제로 검증 → 첫 응시 합격**을 목표로 한다. 2027 상반기를 목표로 하되, 응시일보다 준비 완성도를 우선한다.

## 1. 전체 일정

| 기간 | 집중할 일 | 다음 단계 기준 |
|---|---|---|
| 2026.10~11 | 기초 공백 보완, PG/HTB 15~20대, AD 기초 | 중급 머신에서 정찰·진입 경로를 스스로 찾는다 |
| 2026.11~12 | PEN-200 시작, 약점 모듈 정독 | Linux·Windows 권한 상승과 기본 AD 흐름을 설명하고 재현한다 |
| 2027.01~02 | Challenge Labs, AD·피벗팅 반복, 누적 30~40대 | 저권한 계정부터 도메인 공격 경로를 혼자 연결한다 |
| 2027.03 이후 | 처음 보는 모의시험 세트로 반복 검증 | 3회 연속 목표 초과 달성, 증적·보고서까지 시간 내 완성 |
| 2027.04~05 목표 | 준비 기준을 모두 충족한 뒤 첫 응시 | 시간과 성과에 여유가 검증되면 날짜 확정 |

머신 수는 페이스 확인용이다. **처음 보는 문제를 혼자 해결하는 능력과 시간 여유**로 준비도를 판단한다. 기준 미달이면 학습 기간을 늘린다. 재응시를 전제로 일정을 짜지 않는다.

## 2. 결제·플랫폼 선택

- **시간 여유 우선:** Learn One을 검토. 첫 응시 전 충분히 숙련할 학습 기간을 기준으로 결정한다.
- **비용 우선:** 사전 준비 후 Course + Cert Bundle 검토. 집중 학습 기간을 확보했을 때 선택한다.
- **결제 전 기준:** 중급 머신을 여러 대 시도해 절반 이상 독립 풀이 가능하면 본 과정 진입을 검토한다. 개인 학습 기준이며 공식 요건은 아니다.
- **결제 직전 확인:** 총비용, 시작일, 랩 기간, 응시권 유효기간, 자동 갱신, 기존 구독과의 중복.

| 용도 | 사용할 자료 | 사용 방식 |
|---|---|---|
| 메인 실습 | PG Practice | 중급 중심으로 반복, Linux·Windows 균형 유지 |
| 추가 머신 | HTB Retired | 부족한 기법을 연습할 머신만 선택 |
| 기초 보완 | TryHackMe | 막힌 개념의 룸만 학습하고 실습으로 복귀 |
| AD 보완 | HTB Academy / 기존 AD 노트 | 열거·인증·측면 이동을 하나의 경로로 연결 |
| 종합 연습 | PEN-200 Challenge Labs | 네트워크 전체 흐름과 피벗팅 연습 |

플랫폼을 모두 구독하지 않는다. 메인 실습 하나에 약점 보완 자료만 더한다.

## 3. 공부 순서

**환경·CLI → 정찰 → 웹·초기 침투 → 권한 상승 → AD·피벗팅** 순으로 익히고, 증적·리포트는 첫 머신부터 함께 작성한다.

| 단계 | 핵심 학습 | 통과 기준 / 내부 노트 |
|---|---|---|
| 환경 | VPN, Linux/Bash, 네트워크, 간단한 Python | 접속·파일 전송·스크립트 수정에 막힘 없음 · [환경 설정](../cheatsheets/common/lab-setup/) |
| 정찰 | TCP/UDP, 웹 경로·가상 호스트, SMB/LDAP, 서비스별 열거 | 발견한 서비스마다 다음 확인 항목을 정함 · [정찰](../cheatsheets/01-reconnaissance/) |
| 초기 침투 | 수동 SQLi, 파일 포함·업로드, 명령 주입, 공개 PoC 수정, 셸 안정화 | 취약점 검증부터 셸 획득까지 직접 재현 · [취약점 분석](../cheatsheets/02-vulnerability-analysis/) · [초기 침투](../cheatsheets/03-initial-access/) |
| 권한 상승 | Linux sudo/SUID/cron, Windows 권한·서비스·작업·자격 증명 | 자동 열거 결과에서 실제 공격 가능 조건을 검증 · [권한 상승](../cheatsheets/04-privilege-escalation/) |
| AD·피벗팅 | BloodHound, Kerberos, 자격 증명 재사용, 권한 위임, 터널·라우팅 | 저권한 계정으로 시작해 내부망 이동 경로를 재현 · [AD 정찰](../cheatsheets/01-reconnaissance/active-directory/) |
| 보고서 | 명령어·증적·공격 경로 정리 | 다른 사람이 노트만 보고 풀이를 재현 |

**AD·피벗팅에 학습 시간의 1/3 이상을 배정**하고 Windows 권한 상승을 함께 보강한다. 교재는 아는 부분을 빠르게 확인하고 약점에 시간을 쓴다.

## 4. 주간 실행 루틴

| 시간 | 할 일 |
|---|---|
| 평일 하루 1~1.5시간 | 정찰, 약점 개념 학습, 명령어·노트 정리 |
| 주말 3~4시간 × 2회 | 머신 1~2대를 목표로 침투부터 권한 상승·증적까지 연결 |
| 2주마다 | 반복되는 약점 하나를 골라 다음 2주 집중 |

매 머신은 아래 순서로 진행한다.

1. **독립 시도:** 정찰 결과 → 가설 → 검증 결과를 짧게 기록한다.
2. **막힘 해소:** 30~60분간 진전이 없으면 누락된 열거를 확인하고 최소 힌트만 본다.
3. **재도전:** 힌트를 본 머신은 다음 날 가이드 없이 다시 푼다. 독립 풀이와 구분해 기록한다.
4. **회고:** 핵심 관문 / 놓친 단서 / 다음에 바로 할 행동을 한 줄씩 남긴다.

## 5. 실습·모의시험 체크리스트

| 구간 | 확인할 것 |
|---|---|
| 정찰 | 전체 TCP와 주요 UDP, 서비스 버전, 웹 경로·vhost, 공유·도메인 정보 |
| 웹 | 소스·설정·백업, 로그인, 입력값, 업로드, 버전별 취약점 수동 검증 |
| 셸 확보 | 연결 안정화, 사용자·호스트·IP 확인, 명령어와 증적 저장 |
| Linux 상승 | sudo, SUID/SGID, cron, 쓰기 권한, 설정·히스토리의 자격 증명 |
| Windows 상승 | 사용자 특권, 서비스·파일 ACL, 예약 작업, 설정·레지스트리의 자격 증명 |
| AD | 계정·공유·권한 관계 열거 → 가능한 인증·이동 경로 검증 → 새 정보로 재열거 |
| 피벗팅 | 내부 대역 확인 → 터널·라우팅 구성 → 내부 서비스 접근 검증 |
| 마무리 | 플래그·증적·명령어 누락 확인, 재현 가능한 보고서 작성 |

- AD부터 착수하되 진전이 없으면 독립 머신으로 전환한다.
- 머신당 3~4시간을 초기 타임박스로 삼고, 막히면 현재 가설과 다음 행동을 적어 둔다.
- 식사·휴식·수면을 미리 배치하고 마지막 2~3시간은 증적 정리에 확보한다.
- 모의시험은 AI·풀이 없이 진행하며, 실제 응시에 적용되는 시간·도구·보고서 규칙을 따른다.

## 6. 응시 조건 — 전부 충족할 때만

아래는 첫 응시 합격을 위한 개인 준비 기준이다. 모의시험의 목표는 세트별 평가 기준에 맞춰 사전에 정하고, 합격 수준을 여유 있게 넘기도록 잡는다. 같은 문제 재풀이는 실력 검증 횟수에서 제외한다.

- [ ] 처음 보는 Linux·Windows 중급 머신을 각각 최근 5대 중 4대 이상 힌트 없이 권한 상승까지 완료했다.
- [ ] 서로 다른 AD 환경 3개에서 열거·권한 상승·측면 이동·피벗팅을 혼자 연결했다.
- [ ] 처음 보는 모의시험 세트에서 AI·힌트 없이 3회 연속 목표를 초과 달성했다.
- [ ] 세 번 모두 실습 종료 3시간 전까지 목표를 확보하고, 남은 시간에 증적을 검수했다.
- [ ] 세 번 모두 보고서를 제출 기한 안에 완성하고 명령어·스크린샷·재현 절차의 누락을 점검했다.
- [ ] 식사·휴식·수면을 포함한 일정에서도 성과를 유지했다.
- [ ] 반복되는 약점을 보완한 뒤, 같은 기법이 필요한 다른 머신에서 독립 풀이로 검증했다.
- [ ] 공식 시험 안내에서 채점 기준·허용 도구·AI 제한·증적·제출 기한을 확인했다.
