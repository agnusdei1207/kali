# OSCP 학습 경로 (README)

이 폴더는 OSCP(OffSec Certified Professional) 수준의 침투 테스트 실력을, **공개된 무료 자료만으로** 쌓기 위한 학습 경로입니다.\n유료 OffSec 강의 노트나 유료 플랫폼에 의존하지 않으며, 나중에 강의/시험을 결제하더라도 이 문서의 대부분은 그대로 쓸 수 있습니다. 결제를 강제하지 않습니다.

## 학습 원칙

- "막힌 뒤 배우기": 무료 머신을 직접 공략하면서 막힐 때만 해당 자료를 찾는다.
- 모든 명령과 공격 시도는 본인 소유 또는 허가받은 시스템에서만 수행한다.
- 증적(노트)과 리포트 작성은 05-progress-tracker, 06-pen200-module-map을 참고한다.

> 결제 전 자가 준비: 무료 자료로 15~20대 머신과 AD 기초를 먼저 끝낸 뒤, 필요하면 OffSec 강의/시험을 결제하는 것이 현재 권장 경로입니다.
