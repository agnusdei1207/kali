## 1. 결제 상품과 기간 (공식 페이지 재확인 필수)

| 항목 | Course + Cert Bundle | Learn One |
|------|----------------------|-----------|
| 가격 | $1,749 (1회) | $2,749/년 (자동 갱신) |
| 코스·랩 기간 | 90일 | 365일 |
| 시험 응시 | 1회 | OSCP 2회 (※아래 주) |
| 시작일 | 결제 후 최대 42일(6주) 내 지정 가능 | 결제·등록 즉시 시작, 일시정지 불가 |
| 시험 기한 | 랩 종료일부터 120일 이내 | 구독 기간 내에서만 (끝나면 응시권 소멸) |
| 랩 연장 | 30일 단위 구매 가능 (응시권 미포함) | 없음, 12개월 갱신만 |
| 추가 혜택 | 없음 | PG Practice 200+, KLCP·OSWP 포함 |

> ※ Learn One의 시험 응시 횟수: OSCP 자체는 2회로 안내되지만, 보너스로 딸려 오는 KLCP·OSWP 응시까지 합치면 OffSec FAQ가 총 4회로 표기하기도 한다. OSCP 응시만 몇 회인지는 결제 화면에서 다시 확인할 것.

### 불합격 시 재응시 대기(cooling-off)
- 1차 불합격 → 4주 뒤 재예약
- 2차 불합격 → 8주 / 3차 이후 → 12주
- "실패"한 응시에만 적용되며(취소는 대기 없음), 상품이 아니라 특정 시험 기준으로 횟수를 센다. OSCP에 그대로 적용되는 공식 정책이다.
- 재응시권 별도 구매 약 $249 (공식 확인 필요)

## 2. 타임라인 선택지

### 선택 A — 시간 여유 우선 (권장: 직장인)
```text
지금 ~ 11월     결제 전 자가 준비 (현재 구독 중인 $19 OffSec 구독 + 무료 공개 자료)
11~12월         Learn One 결제 = 즉시 시작, 랩 365일 확보
2027-04~05      1차 응시 (상반기 목표)
불합격 시       4주 뒤 2차 응시 (구독 내)
2027-11~12      구독 만료 (재응시 여유가 충분히 남음)
```
- Bundle보다 랩이 9개월 더 길고(총 12개월), 응시 기회도 1회 더 많으며, PG Practice 1년이 함께 묶여 있다.
- 주당 학습 시간이 적고 한 번에 붙는다고 장담하기 어렵다면, 결국 이쪽이 가장 경제적이다.

### 선택 B — 비용 우선 (충분히 준비된 경우)
```text
지금 ~ 12월     PG Practice로 중급 머신 힌트 없이 절반 이상 풀 수 있을 때까지 자가 준비
12월            Bundle 결제, 시작일을 1월 초로 지정 (최대 42일 지연)
1월 초 ~ 3월 말 랩 90일 집중 (Challenge Labs 위주)
~ 7월 말        랩 종료 후 120일 내 응시 (1회)
```
- 응시 기회가 1회뿐이라 부담이 크다. 그만큼 결제 전에 준비가 탄탄히 돼 있어야 한다.

> 결제 시점 판단 기준: PG Practice Intermediate 난이도 머신을 힌트 없이 절반 이상 풀 수 있으면 본 과정 결제 OK.
> 이 기준은 랩이 90일뿐인 선택 B에서 특히 중요하다. 선택 A(1년)는 결제 시점이 조금 일러도 손해가 적다.

## 4. 주간 루틴 (직장 병행)

```text
주중 (하루 1~1.5h)   노트 정리 · 기법 복습 · 짧은 enumeration (머신 정찰까지만)
주말 (3~4h 몰입 x2)  머신 1~2대 끝까지 공략 — 몰입 블록이 실력을 만든다
```

- 평일엔 "끝내지 못할 머신"을 시작하지 말고, 정찰·분석까지만. 공략은 주말 블록에.
- 2주에 한 번은 [05-progress-tracker.md](./05-progress-tracker.md)를 열어 반복되는 약점 1개를 그 주의 집중 주제로 삼는다.
- 위 루틴은 주 11~15시간 기준이다. 실제 가능 시간이 이보다 적으면 머신 목표 수를 비례해 줄이거나 시험 시기를 늦춘다. 목표 수량만 유지하고 시간을 줄이면 계획이 무너진다.
