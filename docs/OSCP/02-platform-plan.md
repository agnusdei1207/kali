# 02. 플랫폼 활용 전략 (현재는 무료 플랫폼 위주)

> 어떤 플랫폼에서, 어떤 머신을, 어떤 방식으로 풀지. 커리큘럼([01-curriculum.md](./01-curriculum.md))의 각 단계를 실제 머신으로 체화하는 계획.\n> 유료 플랫폼은 현재 사용하지 않는다. 무료 플랫폼이 부족하면 그때 대비해 유료 플랫폼을 검토할 수 있다.

---

## 1. 무료 플랫폼 (현재 사용)

| 플랫폼 | 역할 | 비중 |
|--------|------|------|
| Kali Linux (공식) | 모든 실습의 기반 환경. 모든 명령어와 도구의 정확한 사용법 | 필수 |
| TryHackMe (무료 계정) | AD 기초 룸, 보조 학습. 현재 하는 룸 학습의 연장 | ★ |
| VulnHub (무료) | 오프라인 추가 연습. 시험과 무관한 머신 풀이 | 선택 |
| OffSec Metasploit Unleashed | 무료 공개 과정. OSCP와 가장 유사한 출제사 실력 | ★ |
| OverTheWire (Bandit/Leviathan 등) | bash 기초. 평일 짧은 훈련에 최적 | 필수 |

- Kali는 모든 실습의 기본 환경이다. 설치부터 [../cheatsheets/common/lab-setup/](../cheatsheets/common/lab-setup/)을 참고한다.
- TryHackMe 무료 계정으로 여는 방은 "무료로 쓸 수 있는" 방이다. 유료 방은 사용하지 않는다.
- VulnHub 무료 머신은 `machine` 파일을 직접 받아 랩으로 삼는다(오프라인). 네트워크 연결이 필요한 실습(피벗팅 등)에는 적합하지 않다.
- OffSec의 Metasploit Unleashed는 무료 공개 과정이다. OSCP 시험에서 허용되는 Metasploit 실습을 이 과정으로 익힌다.

---

## 2. 유료 플랫폼 (현재는 사용 안 함 — 대비용)

| 플랫폼 | 비고 |
|--------|------|
| PG Practice | OSCP 시험과 가장 유사한 출제사 실습장. 결제하면 사용할 수 있다. |
| HTB (Retired) / HTB Academy | TJnull·LainKusanagi 리스트의 추가 연습. 결제하면 사용할 수 있다. |
| OSCP (Course & Cert Bundle) | 시험 응시. 결제하면 사용할 수 있다. |

- 두 경로 모두 무료 경로로 충분히 실력을 쌓을 수 있다. 유료 플랫폼을 쓸 때는 이 문서의 "유료" 열을 참고한다.
- 유료 플랫폼을 쓴다면, 먼저 PG Practice의 중급 머신을 힌트 없이 절반 이상 풀 수 있는지 확인한다(00-roadmap 참고).

---

## 3. 머신 선정 — 무료 머신 위에서

- PG Practice, HTB 같은 유료 플랫폼은 사용하지 않는다. 무료 플랫폼만으로 목표 수량을 채운다.
- 무료 플랫폼의 머신을 풀 때도 난이도 배분 가이드를 따른다(01-curriculum 단계별 참고).
- 여러 플랫폼의 머신을 한 번에 두지 않는다. 한 머신을 끝까지 공략한 뒤 다음 머신으로 넘어간다.
  - TryHackMe: 방 하나를 끝까지 공략 → 다음 방
  - VulnHub: 파일 하나를 받아 랩으로 실행 → 끝까지 공략
  - Metasploit Unleashed: 예제 코드와 실습을 차례로 진행

---

## 4. 목표 수량과 페이스 (직장 병행)

```
결제 전 (현재)   PG/HTB 없이 무료 머신만으로 15~20대, AD 모듈 1회독
랩 집중           무료 머신 누적 30~40대. 한 머신 1대 1~2주
반복             약한 단계 재복습 + 모의 시나리오 + 리포트
```

- 주말 몰입 블록(3~4h) 당 무료 머신 1~2대가 현실적 페이스다.
- 평일엔 enumeration/노트까지만, 공략은 주말에.

---

## 5. 시험 직전 4~6주 (유료 시험을 준비한다면)

- OSCP 시험을 응시할 계획이 있으면, 시험 규칙(허용 도구, Metasploit 1대 제한, 리포트 요건)은 OffSec 공식 Exam Guide를 그대로 따른다.
- 이 경로를 무료로만 공부할 때는 시험 응시 준비가 아니라, "모의 시나리오를 스스로 풀어보는 훈련"을 쓴다.
- 세팅: Kali에서 `lhost`/`lport`가 바뀌는 리버스 쉘을 여러 번 만들어 두고, 매번 다른 공격자 IP로 응시하는 연습을 한다.
