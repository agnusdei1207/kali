Node.js 의 Brotli(브로틀리) 압축 해제 결함 · CVE-2026-111497

이동: 방향키 / Space · 전체화면: F

이야기 1. 압축은 "이불 압축팩"과 같다

웹사이트는 글, 이미지, 코드를 인터넷으로 보낼 때 이렇게 부피를 줄여 보냅니다. 받는 쪽은 다시 풀어서 씁니다.

이야기 2. Brotli(브로틀리)는 "작은 빵"

이름은 가볍지만, 지금은 웹 브라우저와 서버가 널리 쓰는 압축 방식입니다. 웹 전송에서는 "br" 이라는 표시로 구분합니다.

이야기 3. 문제는 "만든 쪽"이 아니라 "푸는 쪽"

알아둘 말: 메모리와 힙(heap)

문제: 불량품을 "불량"이라고 말하지 않았다

슬라이드가 열리면 칸이 하나씩 차오릅니다. 8칸이 다 찬 뒤에도 멈추지 않는 것이 핵심입니다.

덮어쓰기가 왜 "명령 실행"까지 가나?

메모리 손상 취약점이 위험해지는 일반적인 원리를 단순화한 그림입니다. Node.js 공지는 이 결함이 크래시, 메모리 노출, 코드 실행으로 이어질 수 있다고 평가합니다.

덮어써지면 어떻게 되나?

"실행까지 가능하다"는 것이 공식 공지의 평가입니다. 실제 피해는 서비스 구성에 따라 달라집니다.

어떤 서비스가 위험한가?

외부에서 받은 압축 데이터를 서버가 직접 풀어주는 곳이 대상입니다.
