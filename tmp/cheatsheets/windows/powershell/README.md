# PowerShell 치트시트

명령을 주제별 파일로 나눠 둔다. 파일명으로 검색(Ctrl+P)해도 찾을 수 있다.

> 관련 문서: [Windows 치트시트](../README.md)

## 파일 목록

- `base_powershell.md` 별칭·도움말·경로 이동·파이프·검색·실행 정책
- `powershell_file_operations.md` 파일·디렉터리 조회/생성/복사/이동/삭제, 플래그 탐색, 해시, ACL
- `powershell_system_reconnaissance.md` OS·환경변수·프로세스·세션·패치·토큰 확인
- `powershell_network_enumeration.md` IP·포트·연결·SMB 공유·원격 명령
- `powershell_user_management.md` 로컬 사용자·그룹 열거
- `powershell_active_directory.md` AD 사용자·그룹·컴퓨터·Kerberos
- `powershell_privilege_escalation.md` 레지스트리·서비스·예약 작업·실행 우회·지속성·자격 증명 덤프
- `powershell_defense_evasion.md` 숨김 속성·로그 삭제·ADS
- `powershell_file_transfer.md` 파일 다운로드(Invoke-WebRequest·certutil)
- `invoke_webrequest.md` Invoke-WebRequest 예시
- `replace.md` 파일 내용 치환
