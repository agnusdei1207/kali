# 침투 테스트 실습 환경

Docker 기반 Kali 환경에서 침투 테스트를 실습하고, 치트시트와 실습 기록을 관리하는 저장소입니다.

## 핵심 원칙

- 허가된 범위에서만 테스트하고, 대상 환경에 남긴 변경은 종료 후 정리합니다.
- 관찰한 정보로 가설을 세우고, 자동화 도구의 결과는 직접 검증합니다.
- 정상 동작과 테스트 결과를 비교해 영향도를 확인합니다.
- 재현 가능한 명령과 증거를 기록하고, 원인과 개선 방안을 함께 남깁니다.

실습 환경은 [`compose.yml`](compose.yml), 세부 자료는 [`docs/`](docs/)를 참고하세요.
