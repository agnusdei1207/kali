# 침투 테스트 실습 환경

## 핵심 철학

- 소거법
- 정상 동작을 기준으로 읽는 작은 차이
- 입력과 권한이 경계를 넘는 순간
- 실패와 오류까지 단서로 삼는 실험
- 자동화로 찾고 손으로 확인한 결과
- 확인된 발판으로만 이어 가는 공격 경로
- 재현 가능한 증거와 설명 가능한 근본 원인
