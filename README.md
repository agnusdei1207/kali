# 침투 테스트 실습 환경

Docker 기반 Kali 환경과 실습 기록을 통해 시스템의 동작, 신뢰 경계, 취약점의 원인을 탐구합니다.

핵심 철학은 관찰에서 가설을 만들고, 경계를 넘는 과정을 검증해, 실제 영향까지 입증하는 것입니다.

## 핵심 원칙

- 정상 흐름을 먼저 재현하고, 조건을 하나씩 바꿔 응답의 차이에서 가설을 세웁니다.
- 입력이 브라우저, 서버, 저장소, 출력 기능을 지나는 동안 어떻게 바뀌고 어느 경계에서 신뢰되는지 추적합니다.
- 관찰, 추정, 입증을 구분합니다. 도구의 판정이나 중간 단계의 성공을 최종 영향으로 간주하지 않습니다.
- 공격 경로는 확인된 사실로만 연결하고, 막힌 단계와 아직 검증하지 못한 전제를 그대로 기록합니다.
- 재현 가능한 최소 증거로 영향과 근본 원인을 설명하고, 개선 방안까지 연결합니다.
- 허가된 범위에서 검증하며, 민감 정보와 대상 환경의 변경 사항은 안전하게 다룹니다.

실습 환경은 [`compose.yml`](compose.yml), 세부 자료는 [`docs/`](docs/)를 참고하세요.
